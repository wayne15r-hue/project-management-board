# My Work Implementation Plan

Approved spec: the user's Feature 1 implementation request in this chat.
Goal: personal open assignments and owned-board attention without expanding access.
Architecture: security-invoker PostgreSQL aggregation RPC for filtering/counts/paging, authenticated route, React Query client and shared editor. Additive blocked fields and invariant trigger; existing move RPC retains atomic metadata updates.
Stack: existing Next.js 16/React/Supabase/PostgreSQL/Vitest; no dependencies.

## Constraints and decisions
- My Work = assigned tasks; attention = assigned OR owned board AND overdue/blocked. Always existing RLS.
- Local-day overdue using validated IANA zone, UTC fallback; complete = normalized Done/Completed or final column with >=2 columns. No existing dashboard changes.
- Page size 50, full matching counts, due ascending/null last, high first, ID tie-break.
- No approvals, notifications, escalations or automations in this release.
- Retain legacy code compatibility; migration first, no destructive rollback.
