# Helios incoming-call tune sketches

Four original, procedurally composed and synthesized instrumental loops:
Dawn Chimes, Warm Keys, Soft Marimba, and Orbit Bells.

No third-party music, recordings, samples, or streaming services are used.
These source compositions and generated assets are supplied for unrestricted
use, modification, and distribution, including commercial use, without fees
or attribution requirements. To the extent copyright applies, the creator
dedicates these contributions to the public domain under CC0 1.0.

Each WAV is six seconds, mono, 44.1 kHz, 16-bit PCM, with a quiet loop gap and
short attack/release envelopes. The instrument names describe synthesized
timbres. Regenerate with `python scripts/generate-ringtones.py` from the repository root.

These are audition candidates. File decoding, peak levels, and browser playback
can be checked automatically; pleasantness and listening comfort require the
user to audition them. These files are bundled with Helios; production behavior changes only after an authorized deployment.
